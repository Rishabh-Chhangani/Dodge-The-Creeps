# Session 13: Godot Editor Exclusive Window Collision Troubleshooting

**Date:** 2026-10-11  

---

### User Error Log

```text
ERROR: scene/main/window.cpp:1050 - Attempting to make child window exclusive, but the parent window already has another exclusive child. This window: /root/@EditorNode@20438/@Panel@14/@VBoxContainer@15/DockHSplitLeftL/DockHSplitLeftR/DockHSplitMain/@VBoxContainer@26/DockVSplitCenter/@VSplitContainer@62/@VBoxContainer@63/@EditorMainScreen@103/MainScreen/@WindowWrapper@12615/@ScriptEditor@12614/@ConfirmationDialog@12394, parent window: /root, current exclusive child window: /root/@EditorNode@20438/@Panel@14/@ConfirmationDialog@9337
```

---

### Diagnosis & Explanation

1. **Source of the Warning**:
   - This error is emitted by the **Godot Editor UI**, not by gameplay code or runtime scripts.
   - An "exclusive" window is a modal dialog (such as a confirmation prompt or settings panel) that blocks focus to the parent window until dismissed.
   - Godot's `Window` manager allows only **one** exclusive child window per parent window.

2. **Trigger**:
   - The editor already had an open exclusive dialog (`/root/@EditorNode@20438/@Panel@14/@ConfirmationDialog@9337` — e.g. "Save Scene?", "Project Settings", or an alert prompt).
   - Simultaneously, external file additions on disk (`tests/` scripts and `.uid` generation) prompted the Script Editor to spawn a "Reload files from disk?" dialog (`@ScriptEditor@12614/@ConfirmationDialog@12394`).
   - The second modal could not be made exclusive because the first modal was still open.

3. **Resolution**:
   - In Godot Editor, look for and dismiss the active modal dialog (click **Reload**, **OK**, or press `Escape` / `Enter`).
   - If the editor feels locked, restart Godot to reload all new files cleanly.
   - The 5 new `tests/*.gd.uid` resource files generated by Godot have been tracked in Git.
